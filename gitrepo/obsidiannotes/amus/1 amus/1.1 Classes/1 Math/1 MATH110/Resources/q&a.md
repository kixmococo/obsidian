As you progress through the class, there is a **Q&A Discussion** that allows you to talk to each other and ask questions to the instructor.

- If you have a question about something in the course you do not understand, please post it in the **Q&A Discussion**.  If you have a question it is very likely that others will have the same question too!  By asking the question you not only help yourself, you'll be helping others too.  
- If you have a non-personal question about the course, please post it in the **Q&A Discussion**. Other students will be able to see your question and the instructor's response so if you have a question that can benefit the entire class, go for it!
- If you have a question that is more sensitive in nature, please email the instructor.

The Q&A Discussion is located in the [Discussions area](https://myclassroom.apus.edu/d2l/common/dialogs/quickLink/quickLink.d2l?ou=180694&type=discuss&rcode=00D22884-7DC5-4408-809B-589E36B04C5A-452).
