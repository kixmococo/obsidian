[Chapter 1: Foundations](https://myclassroom.apus.edu/shared/commonfolder/science-and-technology-common/Math/Math110%20LimeSpring/Resource%20Center/Lessons/Foundations/Foundations.pdf)

[1.1 Use the Language of Algebra](https://cnx.org/contents/AndhM9Sd@14.1:02l1UzkA@20/1-1-Use-the-Language-of-Algebra)

• Find factors, prime factorizations, and least common multiples  
• Use variables and algebraic symbols  
• Simplify expressions using the order of operations  
• Evaluate an expression  
• Identify and combine like terms  
• Translate an English phrase to an algebraic expression

[1.2 Integers](https://cnx.org/contents/AndhM9Sd@14.1:BeqwOW0c@20/1-2-Integers)

• Simplify expressions with absolute value  
• Add and subtract integers  
• Multiply and divide integers  
• Simplify expressions with integers  
• Evaluate variable expressions with integers  
• Translate phrases to expressions with integers  
• Use integers in applications

[1.3 Fractions](https://cnx.org/contents/AndhM9Sd@14.1:QlYg2VHd@21/1-3-Fractions)

• Simplify fractions  
• Multiply and divide fractions  
• Add and subtract fractions  
• Use the order of operations to simplify fractions  
• Evaluate variable expressions with fractions

[1.4 Decimals](https://cnx.org/contents/AndhM9Sd@14.1:mbIpaplX@18/1-4-Decimals)

• Round decimals  
• Add and subtract decimals  
• Multiply and divide decimals  
• Convert decimals, fractions, and percents  
• Simplify expressions with square roots  
• Identify integers, rational numbers, irrational numbers, and real numbers  
• Locate fractions and decimals on the number line

[1.5 Properties of Real Numbers](https://cnx.org/contents/AndhM9Sd@14.1:mH2g0CNm@22/1-5-Properties-of-Real-Numbers)

• Use the commutative and associative properties  
• Use the properties of identity, inverse, and zero  
• Simplify expressions using the Distributive Property
