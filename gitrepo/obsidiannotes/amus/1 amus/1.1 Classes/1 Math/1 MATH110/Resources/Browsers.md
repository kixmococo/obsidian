# Recommended Browsers

- Edge, Chrome or Firefox browsers are supported by LimeSpring - Internet Explorer is NOT.
- You decide which of the three recommended browsers works best for you.
- For technical issues in any of those three browsers, first try clearing browser history. 
- Changing browsers (for example, from Firefox to Chrome or Edge) also may alleviate the issue. 
- If the problem is not fixed by either clearing browser history or changing browsers, contact LimeSpring support.  [support@limespring.com(this link opens in a new window/tab)](mailto:support@limespring.com)  or [ClassroomSupport@apus.edu (this link opens in a new window/tab)](mailto:ClassroomSupport@apus.edu)
