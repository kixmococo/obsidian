# C# Cheatsheet: File -> Array -> String -> Char -> Int
_A linear beginner guide to pulling an integer from a character in text file data_

---

## What this cheatsheet is about

This guide explains one very specific beginner idea in a slow, linear way:

How do you pull an `int` from:

- a `char`
- that came from a `string`
- that came from a `string[]`
- that came from a text file like `document.txt`

This chain can feel confusing because there are several layers involved.

So the goal here is to walk through it one layer at a time.

---

# Part 1: The full chain

The idea is:

**file** -> **array of lines** -> **one line string** -> **one character** -> **integer**

That is the whole path.

You are basically peeling away one layer at a time.

---

# Part 2: Start with the file

Suppose `document.txt` contains:

```text
7abc
2xyz
```

That file is just text sitting on disk.

Right now, C# has not read it yet.

---

# Part 3: Read the file into C#

If you do this:

```csharp
string[] lines = File.ReadAllLines("document.txt");
```

then C# reads the file and turns it into a **string array**.

Now `lines` contains:

- `lines[0]` = `"7abc"`
- `lines[1]` = `"2xyz"`

So what happened?

- the file had 2 lines
- each line became a string
- all the strings were stored in an array

You can picture it like this:

```csharp
string[] lines = { "7abc", "2xyz" };
```

That is basically what C# gave you.

---

# Part 4: Pick one string from the array

Now suppose you want the first line.

You do:

```csharp
string firstLine = lines[0];
```

Now `firstLine` becomes:

```csharp
"7abc"
```

Important:
At this point you are no longer dealing with the whole file or the whole array.

Now you are dealing with **one string**.

---

# Part 5: Pick one character from the string

Strings have indexes.

So if you do this:

```csharp
char firstChar = firstLine[0];
```

that means:

- go to the first string: `"7abc"`
- grab the character at index `0`

Now `firstChar` becomes:

```csharp
'7'
```

Important:

- `"7abc"` is a **string**
- `'7'` is a **char**

Those are not the same type.

---

# Part 6: Convert the char into an int

Now you have:

```csharp
char firstChar = '7';
```

But `int.Parse()` does **not** take a `char` directly.

It wants a `string`.

So first you turn the char into a string:

```csharp
firstChar.ToString()
```

That turns:

```csharp
'7'
```

into:

```csharp
"7"
```

Then you parse it:

```csharp
int number = int.Parse(firstChar.ToString());
```

Now `number` becomes:

```csharp
7
```

---

# Part 7: Full version, step by step

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        // Step 1: Read all lines from the file into a string array
        string[] lines = File.ReadAllLines("document.txt");

        // Step 2: Take the first line from that array
        string firstLine = lines[0];

        // Step 3: Take the first character from that string
        char firstChar = firstLine[0];

        // Step 4: Convert that char into a string, then parse it into an int
        int number = int.Parse(firstChar.ToString());

        Console.WriteLine(number);
    }
}
```

If the first line starts with `7`, this prints:

```text
7
```

# Part 8: Read the code in plain English

This line:

```csharp
string[] lines = File.ReadAllLines("document.txt");
```

means:

> "Read the file and give me all its lines."

This line:

```csharp
string firstLine = lines[0];
```

means:

> "Give me the first line."

This line:

```csharp
char firstChar = firstLine[0];
```

means:

> "Give me the first character of that first line."

This line:

```csharp
int number = int.Parse(firstChar.ToString());
```

means:

> "Turn that character into text, then turn that text into an integer."

# Part 9: The same idea in one line

Once you understand the layers, this works too:

```csharp
int number = int.Parse(File.ReadAllLines("document.txt")[0][0].ToString());
```

This does the same thing as the long version.

But it is harder to read.

For learning, the longer step-by-step version is much better.

---

# Part 10: Why the one-line version works

Look at this carefully:

```csharp
File.ReadAllLines("document.txt")
```

This gives a `string[]`

Then:

```csharp
File.ReadAllLines("document.txt")[0]
```

This gives the first `string`

Then:

```csharp
File.ReadAllLines("document.txt")[0][0]
```

This gives the first `char` of the first string

Then:

```csharp
File.ReadAllLines("document.txt")[0][0].ToString()
```

This turns that char into a string

Then:

```csharp
int.Parse(...)
```

turns that string into an int

So the one-liner is just all the layers smashed together.

# Part 11: Safer version

What if:

- the file is empty?
- the first line is empty?
- the first character is not a digit?

Then the simple version can fail.

Safer version:

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string[] lines = File.ReadAllLines("document.txt");

        if (lines.Length == 0)
        {
            Console.WriteLine("The file has no lines.");
            return;
        }

        string firstLine = lines[0];

        if (firstLine.Length == 0)
        {
            Console.WriteLine("The first line is empty.");
            return;
        }

        char firstChar = firstLine[0];

        if (int.TryParse(firstChar.ToString(), out int number))
        {
            Console.WriteLine("The number is: " + number);
        }
        else
        {
            Console.WriteLine("The first character is not a valid digit.");
        }
    }
}
```

---

# Part 12: Why the safe version matters

The simple version assumes:

- the file exists
- the file has at least one line
- the first line has at least one character
- the first character is numeric

Those assumptions are okay for very controlled practice.

But real programs often need to defend against bad data.

That is why checks like these are useful:

```csharp
if (lines.Length == 0)
```

and

```csharp
if (firstLine.Length == 0)
```

and

```csharp
if (int.TryParse(...))
```

# Part 14: Memory hook

Think of it like peeling layers:

- `File.ReadAllLines(...)` gives you **many strings**
- `lines[0]` gives you **one string**
- `firstLine[0]` gives you **one char**
- `ToString()` gives you **a string again**
- `int.Parse(...)` gives you **an int**

So the path is:

**text file**  
-> **string[]**  
-> **string**  
-> **char**  
-> **string**  
-> **int**

# Part 15: Tiny recap

## File
Stores text.

## `ReadAllLines`
Turns the file into a `string[]`.

## `lines[0]`
Gets one line from the array.

## `firstLine[0]`
Gets one char from the string.

## `ToString()`
Turns the char into text.

## `int.Parse()`
Turns the text into an integer.
