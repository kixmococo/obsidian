# C# Cheatsheet: Reading Text Files, File Manipulation, and Processing File Data
_A simple, detailed, overexplained guide_

---

## What this cheatsheet is about

This guide teaches the beginner C# workflow around text files:

- how to read text files
- how to write text files
- how to append to text files
- how to check if files exist
- how to work with file paths
- how to split file content into lines
- how to process file data
- how to convert text from files into numbers
- how to loop through file content safely

This matters because a lot of real programs need to do things like:

- load settings
- read logs
- process lists of values
- read names from files
- read rows of numbers
- transform one file into another
- summarize file data

A file often starts as text, then your job is to turn that text into useful program data.

# Part 1: The main idea

A text file is just stored text.

When C# reads a text file, it usually gives you:

- one big string
- or an array of lines

Then you process that data using things like:

- loops
- strings
- arrays
- `Split()`
- `Parse()`
- `TryParse()`

So file processing is really a combination of many beginner skills working together.

# Part 3: Read an entire file as one string

Use `File.ReadAllText()`.

## Example

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string text = File.ReadAllText("data.txt");
        Console.WriteLine(text);
    }
}
```

## What happens

- C# opens `data.txt`
- reads the entire file
- stores all its text into one big string called `text`

This is good when you want the whole file at once.

---

# Part 4: Read a file as lines

Use `File.ReadAllLines()`.

## Example

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string[] lines = File.ReadAllLines("data.txt");

        foreach (string line in lines)
        {
            Console.WriteLine(line);
        }
    }
}
```

## What happens

- each line of the file becomes one string
- all those strings go into an array

This is one of the most useful beginner file methods.

---

# Part 5: `ReadAllText` vs `ReadAllLines`

## `File.ReadAllText()`
Use when you want:

- one big string
- the whole file all at once
- to split/process it yourself later

## `File.ReadAllLines()`
Use when you want:

- line-by-line data
- easier row processing
- a string array immediately

Very often, beginners like `ReadAllLines()` because many text file tasks are line-based.

# Part 8: Convert file lines into numbers

If the file contains numbers, you often parse each line.

## Example

```csharp
string[] lines = File.ReadAllLines("numbers.txt");

for (int i = 0; i < lines.Length; i++)
{
    int number = int.Parse(lines[i]);
    Console.WriteLine(number * 2);
}
```

If the file contains:

```text
10
20
30
40
```

output becomes:

```text
20
40
60
80
```

# Part 9: Safer parsing from files

Files can contain bad data too.

So `TryParse()` is often smarter than `Parse()`.

## Example

```csharp
string[] lines = File.ReadAllLines("numbers.txt");

for (int i = 0; i < lines.Length; i++)
{
    if (int.TryParse(lines[i], out int number))
    {
        Console.WriteLine("Valid number: " + number);
    }
    else
    {
        Console.WriteLine("Bad line: " + lines[i]);
    }
}
```

This keeps your program from crashing on messy input.

## Code

```csharp
string[] lines = File.ReadAllLines("numbers.txt");
```

# Part 11: Read comma-separated data

Imagine a file line looks like this:

```text
Kai,20,175
```

You can split the line.

## Example

```csharp
string[] lines = File.ReadAllLines("people.txt");

for (int i = 0; i < lines.Length; i++)
{
    string[] parts = lines[i].Split(',');

    string name = parts[0];
    int age = int.Parse(parts[1]);
    int height = int.Parse(parts[2]);

    Console.WriteLine(name + " is " + age + " years old and " + height + " cm tall.");
}
```

This is very common:

- read line
- split line
- parse pieces
- use the data

# Part 26: Read line-by-line with a stream

For huge files, sometimes you do not want the whole thing at once.

You can use `StreamReader`.

## Example

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        using (StreamReader reader = new StreamReader("data.txt"))
        {
            string line;

            while ((line = reader.ReadLine()) != null)
            {
                Console.WriteLine(line);
            }
        }
    }
}
```

This reads one line at a time.

For beginners, `ReadAllLines()` is often easier, but this is useful to know.

# Part 32: Example: process CSV-like lines safely

Suppose lines look like:

```text
Kai,20,175
Mira,19,168
BadData
Sol,22,180
```

Safer version:

```csharp
string[] lines = File.ReadAllLines("people.txt");

for (int i = 0; i < lines.Length; i++)
{
    string line = lines[i].Trim();

    if (line == "")
    {
        continue;
    }

    string[] parts = line.Split(',');

    if (parts.Length != 3)
    {
        Console.WriteLine("Bad line format: " + line);
        continue;
    }

    string name = parts[0];

    if (int.TryParse(parts[1], out int age) &&
        int.TryParse(parts[2], out int height))
    {
        Console.WriteLine(name + " | age " + age + " | height " + height);
    }
    else
    {
        Console.WriteLine("Bad numeric data: " + line);
    }
}
```

This shows a more realistic safe-processing style.

# Part 33: Common beginner mistakes

## Mistake 1: Forgetting file data is text

Even if a file contains numbers, once read, those values usually start as strings.

You still must parse them.

## Mistake 2: Using `Parse()` on messy files

If the file may contain junk, `Parse()` can crash.

Use `TryParse()` when the data is uncertain.

## Mistake 3: Forgetting `.Trim()`

Extra spaces and newlines can cause problems.

`Trim()` often helps a lot.

## Mistake 4: Going out of bounds after `Split()`

If you expect 3 pieces:

```csharp
string[] parts = line.Split(',');
```

do not blindly use `parts[2]` unless you know the line really had 3 pieces.

## Mistake 5: Not checking file existence

If the file is missing, reading it fails.

`File.Exists()` is helpful.

## Mistake 6: Accidentally overwriting files

`File.WriteAllText()` and `File.WriteAllLines()` replace existing content.

If you want to add instead, use append methods.

# Part 35: Final sample program

This program:

- checks if a file exists
- reads lines
- skips blank lines
- parses valid numbers
- totals them
- writes a report file

```csharp
using System;
using System.IO;

class Program
{
    static void Main()
    {
        string inputPath = "numbers.txt";
        string outputPath = "report.txt";

        if (!File.Exists(inputPath))
        {
            Console.WriteLine("Input file not found.");
            return;
        }

        string[] lines = File.ReadAllLines(inputPath);

        int total = 0;
        int validCount = 0;
        int badCount = 0;

        for (int i = 0; i < lines.Length; i++)
        {
            string line = lines[i].Trim();

            if (line == "")
            {
                continue;
            }

            if (int.TryParse(line, out int number))
            {
                total += number;
                validCount++;
            }
            else
            {
                Console.WriteLine("Bad line: " + line);
                badCount++;
            }
        }

        string report =
            "File report\n" +
            "-----------\n" +
            "Valid numbers: " + validCount + "\n" +
            "Bad lines: " + badCount + "\n" +
            "Total: " + total + "\n";

        File.WriteAllText(outputPath, report);

        Console.WriteLine("Done. Report written to " + outputPath);
    }
}
```
