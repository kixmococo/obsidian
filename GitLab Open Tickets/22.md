## Audio Manager Setup

Open created 2 weeks ago by [Andres Gutierrez](https://gitlab.com/AndresGutierrez414 "Andres Gutierrez")

# Project Task Summary[](https://gitlab.com/team-gomgom/project-gomgom/-/boards?show=eyJpaWQiOiIyMiIsImZ1bGxfcGF0aCI6InRlYW0tZ29tZ29tL3Byb2plY3QtZ29tZ29tIiwiaWQiOjE5NTkwNzMwOX0%3D#project-task-summary)

Create a global audio manager autoload that provides centralized control over music, sound effects, and audio volume settings.

The manager should remain available across scene changes and prevent individual gameplay scripts from needing to manage global audio directly.

## Expected behavior[](https://gitlab.com/team-gomgom/project-gomgom/-/boards?show=eyJpaWQiOiIyMiIsImZ1bGxfcGF0aCI6InRlYW0tZ29tZ29tL3Byb2plY3QtZ29tZ29tIiwiaWQiOjE5NTkwNzMwOX0%3D#expected-behavior)

- [ ]  Contains dummy data (actual data can be inserted later) representing the user's audio settings (master volume, music volume, etc.)
    
- [ ]  Loads when the project starts and can be accessed from any scene or script.
    
- [ ]  Provide an example method for changing the dummy audio settings.
    
- [ ]  Provide an example signal when the dummy audio state changes.
