## In-Game Menu

Open created 2 weeks ago by [Andres Gutierrez](https://gitlab.com/AndresGutierrez414 "Andres Gutierrez")

# Feature Task Summary[](https://gitlab.com/team-gomgom/project-gomgom/-/boards?show=eyJpaWQiOiIyMyIsImZ1bGxfcGF0aCI6InRlYW0tZ29tZ29tL3Byb2plY3QtZ29tZ29tIiwiaWQiOjE5NTkwNzkwNn0%3D#feature-task-summary)

A reusable menu that can be opened in-game (as opposed to the main menu which is loaded before any level) for accessing nested settings and leaving the game.

The menu should work during gameplay and be structured so additional settings—such as graphics, controls, and accessibility—can be added later.

## Expected behavior[](https://gitlab.com/team-gomgom/project-gomgom/-/boards?show=eyJpaWQiOiIyMyIsImZ1bGxfcGF0aCI6InRlYW0tZ29tZ29tL3Byb2plY3QtZ29tZ29tIiwiaWQiOjE5NTkwNzkwNn0%3D#expected-behavior)

- [ ]  Pressing ESC (changeable after [#29](https://gitlab.com/team-gomgom/project-gomgom/-/work_items/29 "Keyboard/Controller Mapping Window") is complete) opens and closes the window.
    
- [ ]  The mouse cursor is visible while menu is open.
    
- [ ]  Player input for the game should be disabled while the window is opened.
    
- [ ]  A Resume button exists for closing the in-game menu and returning to the gameplay.
    
- [ ]  A Main Menu button lets player leave the game and return to main menu.
    
- [ ]  A Close Game button (preferably not near the Main Menu button) makes player exit application.
    
- [ ]  A Settings button exists that connects to the in-game settings menu (attached to [#34](https://gitlab.com/team-gomgom/project-gomgom/-/work_items/34 "In-Game Settings Menu") if completed).
